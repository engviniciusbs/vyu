# vyu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Windows desktop app that shows 2–6 Tapo/RTSP cameras live, with per-camera audio, on a free-form canvas the user arranges.

**Architecture:** One Rust binary. Pure-logic modules (`canvas`, `config`, `stream::{url,quality,backoff,session}`, `audio::mixer`) are unit-tested without hardware. Thin adapters wrap FFmpeg (`stream::ffmpeg`), cpal (`audio::output`), Credential Manager (`secrets`) and the registry (`autostart`). `app` draws everything with egui.

**Tech Stack:** Rust 2024 (stable MSVC), eframe/egui 0.37 (wgpu), ffmpeg-next 9 (FFmpeg 9.0 LGPL shared), cpal 0.18, ringbuf 0.6, keyring 4 (v1), winreg 0.56, serde/serde_json, uuid, tracing + tracing-appender, percent-encoding, directories.

**Spec:** `docs/superpowers/specs/2026-11-02-vyu-design.md`

## Global Constraints

- Build env: `FFMPEG_DIR=vendor/ffmpeg` (set in `.cargo/config.toml` `[env]`, relative), `LIBCLANG_PATH` from the user's env (`pip install --user libclang`); `vendor/ffmpeg/bin` on PATH to run.
- Config at `%APPDATA%\vyu\config.json`, `"version": 1`; logs at `%APPDATA%\vyu\logs\vyu.log` (daily rotation).
- Passwords only in Credential Manager, service `vyu`, user `<camera_id>` (target shows as `vyu:<camera_id>`); never in JSON or logs.
- RTSP: `rtsp://{user}:{pass}@{host}:{port}/stream1|stream2`, percent-encoded userinfo, `rtsp_transport=tcp`, open/read timeout 5 s.
- Auto quality: `stream1` above 540 physical px tile height, back to `stream2` below 400 px, after 1 s stable.
- Reconnect backoff: 1, 2, 4, 8, 16, 30 s (cap), forever; 401 → `AuthFailed`, no retry.
- Stall: no frame for 5 s → reconnect.
- Audio: f32 mono 48 kHz per camera; all tiles start muted; mix clamps to [-1, 1].
- Canvas: tiles normalized 0–1; min size 120×68 px; snap 8 px; `Shift` locks 16:9; `Alt` disables snap; new tile centered, 40 % width, 16:9, top z.
- Floating bar hides after 2 s idle. Config save debounced 500 ms, atomic (`.tmp` + rename).
- UI copy in Portuguese (pt-BR). Code identifiers and comments in English.
- Release build uses `windows_subsystem = "windows"`.
- Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; one commit per task (or more), conventional-commit prefixes.

## Review Focus

1. Password containing `@ : / # %` or spaces → URL still valid, camera connects; masked in logs. (Task 3 test `url_encodes_special_chars`.)
2. Window shrunk or moved to a smaller monitor → no tile lost off-screen; tiles clamped into the window. (Task 4 test `clamp_keeps_tile_inside`.)
3. Camera deleted while referenced by other layouts → those tiles vanish everywhere, no crash. (Task 2 test `remove_camera_prunes_all_layouts`.)
4. Quality switch changes resolution mid-session (1080p ↔ 360p) → scaler rebuilt, no garbled frame. (Task 6: scaler keyed by `(w, h, fmt)`; Task 5 test `quality_change_restarts_source`.)
5. Camera without audio track, or audio at a rate other than 8 kHz → video still plays, resampled to 48 kHz or mute button disabled. (Task 6: `has_audio` reported in `SessionStatus`; Task 7 test `missing_source_is_silence`.)

### Task 5: session logic (quality, backoff, state machine)

**Files:** Create `src/stream/quality.rs`, `src/stream/backoff.rs`, `src/stream/session.rs`, `src/stream/frame.rs`

**Interfaces:**
- Consumes: `StreamVariant`, `url::rtsp_url` (Task 3).
- Produces:
  - `frame::Frame { width: u32, height: u32, rgba: Vec<u8>, seq: u64 }`; `type SharedFrame = Arc<Mutex<Option<Frame>>>`
  - `quality::AutoQuality::new() ; update(&mut self, tile_h_px: f32, now: Instant) -> StreamVariant` (starts `Low`; thresholds 540/400; 1 s stability)
  - `backoff::Backoff::new(); next(&mut self) -> Duration; reset(&mut self)` (1,2,4,8,16,30,30…)
  - `enum SessionStatus { Connecting, Live { has_audio: bool }, Reconnecting { attempt: u32, retry_in: Duration, reason: String }, AuthFailed, Stopped }`
  - `enum SourceError { Auth, Unreachable(String), Stalled, Other(String) }`
  - `enum SourceEvent { Video(Frame), Audio(Vec<f32>) }`
  - `trait Source: Send { fn next_event(&mut self) -> Result<SourceEvent, SourceError>; fn has_audio(&self) -> bool; }`
  - `trait SourceFactory: Send + 'static { fn open(&self, v: StreamVariant) -> Result<Box<dyn Source>, SourceError>; }`
  - `enum Command { SetVariant(StreamVariant), Stop }`
  - `Session::spawn(factory: impl SourceFactory, initial: StreamVariant, audio_tx: AudioSink, ctx_repaint: Box<dyn Fn() + Send>) -> SessionHandle`
  - `SessionHandle { frame: SharedFrame, status: Arc<Mutex<SessionStatus>>, fn send(&self, Command), fn variant(&self) -> StreamVariant }`; `Drop` sends `Stop` and joins.
  - `AudioSink` = `Box<dyn FnMut(&[f32]) + Send>` (Task 7 supplies the ring-buffer producer).

- [ ] **Step 1: Failing tests** (fake `SourceFactory` scripted with a `VecDeque` of results; backoff sleeps go through an injectable `sleep: fn(Duration)` / test uses a no-op):

  - `auto_quality_hysteresis`: 600 px held 1 s → High; 450 px → stays High; 350 px held 1 s → Low; 600 px for 0.5 s → stays Low.
  - `live_publishes_frames`: factory yields one source emitting 3 frames then `Stopped` cmd → `frame` holds seq 3, status was `Live`.
  - `auth_error_stops_retrying`: open returns `Auth` → status `AuthFailed`, factory called exactly once.
  - `unreachable_retries_with_backoff`: open fails `Unreachable` twice then succeeds → status reaches `Live`, factory called 3 times, recorded sleeps 1 s, 2 s.
  - `quality_change_restarts_source`: `SetVariant(High)` while live → factory reopened with `High`, last frame kept until a new one arrives.
- [ ] **Step 2:** `cargo test stream` → FAIL.
- [ ] **Step 3:** Implement the session loop on a `std::thread`: open → read events (check command channel with `try_recv` between events) → on error update status, sleep backoff in 100 ms slices (so `Stop` is responsive), reopen. Backoff resets after the first frame of a successful open.

### Task 7: audio mixer + output

**Files:** Create `src/audio/mod.rs`, `src/audio/mixer.rs`, `src/audio/output.rs`

**Interfaces:**
- Produces:
  - `mixer::Mixer::new() ; add_source(&mut self, id: Uuid) -> AudioSink ; remove_source(&mut self, id) ; set_gain(&self, id, volume: f32, muted: bool) ; fill(&mut self, out: &mut [f32])` (mono; consumes from each source's ring buffer, multiplies by gain, sums, clamps)
  - Ring buffer per source: `ringbuf::HeapRb<f32>` capacity 48 000 × 0.5 s; producer pushes and drops on overflow; consumer skips ahead when > 250 ms buffered (keeps latency low).
